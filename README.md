# Hotelaz

Aplikasi manajemen hotel berbasis Laravel untuk mengelola data kamar, pemesanan, dan alur operasional hotel.

## Teknologi

- Laravel
- PHP
- Vite
- Tailwind CSS

## Menjalankan secara lokal

```bash
composer install
cp .env.example .env
php artisan key:generate
npm install
npm run build
php artisan migrate
php artisan serve
```

Sesuaikan koneksi database di `.env` sebelum menjalankan migrasi.
